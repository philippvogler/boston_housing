# Seasonal Market Analysis Dashboard

A React dashboard for visualizing historical monthly return patterns across 13 global indices and commodities.

## Features

- **Heatmap Overview** - Color-coded monthly returns, win rates, and median returns for all assets
- **Asset Detail** - Deep dive into any asset with bar charts, cumulative seasonal patterns, and full statistics
- **Compare Assets** - Side-by-side comparison of up to 5 assets

## Assets Covered

- **US Indices**: Dow Jones, S&P 500, NASDAQ, Russell 2000
- **European Indices**: Euro Stoxx 50, DAX, FTSE 100
- **Asia**: Nikkei 225
- **Precious Metals**: Gold, Silver, Platinum
- **Industrial & Energy**: Copper, Crude Oil (WTI)

## Getting Started

```bash
npm install
npm run dev
```

## Data Sources

Compiled from Barchart, Equity Clock, BullionVault, Trade That Swing, and academic research (2000-2024 for indices, 2004-2024 for commodities).

## Disclaimer

Past performance does not guarantee future results. Seasonal patterns are statistical tendencies, not predictions.
